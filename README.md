# Трекер v2

Убрана цель про порно/мастурбацию. Добавлены настройки целей.

## Обновление
1. В Supabase SQL Editor запусти `supabase_v2.sql`.
2. Замени в GitHub `index.html`, `style.css`, `app.js` на версии из этого архива.
3. Свой текущий `config.js` оставь как есть.
4. После push GitHub Pages задеплоит новую версию.

## Как менять цели
На сайте нажми **⚙️**.
- ✏️ изменить emoji, название и описание;
- 🗑️ удалить;
- **＋ Добавить цель** создать новую.

Threads остаётся отдельным счётчиком с лимитом 30 минут.

## v4 — полноценный календарь
- Календарь больше не привязан к октябрю 2026.
- Можно переключать месяцы кнопками `‹` / `›`.
- Есть выпадающий список месяцев и лет.
- В каждом месяце автоматически учитывается правильное количество дней.
- Данные берутся по реальной дате `YYYY-MM-DD`, поэтому история сохраняется между месяцами.
- Добавлена статистика месяца: выполнений, полных дней и процент выполнения.
- Можно листать месяцы вперёд и назад.
